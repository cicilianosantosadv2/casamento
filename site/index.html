    Como foi feito

    1. Fotografias

      As fotos foram lidas das pastas originais sem alteração. Duplicadas foram removidas por impressão digital (SHA-256), e a ordem segue os capítulos do dia.

    2. Votos

      O texto de cada voto foi conferido palavra por palavra contra o documento original. A narração usa vozes sintéticas em português (Edge TTS), sem cortes e sem aceleração.

    3. Trilha

      Gymnopédie No. 1, de Erik Satie, ao piano de Robin Alciatore. Gravação em domínio público, do Wikimedia Commons. A música baixa sozinha enquanto há voz.

    4. Montagem

      Cada cena é um componente React renderizado com Remotion: movimento lento nas fotos, transições suaves, abertura e encerramento próprios.

    5. Capítulos

      Esta página abre o mesmo filme no ponto exato de cada capítulo, calculado a partir da linha do tempo do Remotion.

    6. Aprovação

      O render final só roda depois que o casal marca seis aprovações: fotos, cronologia, cada voz, trilha e montagem.

    Por trás das cenas

    O código está no GitHub: cicilianosantosadv2/casamento.

    O repositório guarda só o código e o roteiro técnico. Fotos, documentos dos votos e áudios ficam fora dele.

    Ferramentas: Remotion 4, React, TypeScript, Node.js, Python, FFmpeg e Edge TTS.

    Para gerar o filme final: npm run render.
